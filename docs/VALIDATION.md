## 2026-10-01：两轮可靠性与体验优化

本轮保持原生 JavaScript、本机 HTTP、IndexedDB v2 和既有备份格式。全部验证使用合成数据、模拟上游及隔离浏览器，未访问或改写个人使用的 4173 来源。

完成内容：

- 主线确认与候选接受独立，直接保存、只改时刻和恢复草稿均不会静默采用候选；明确接受后才替换、归档。身份、坐标及途经点变化继续使旧路线失效。
- 批量、事务、恢复和筛选共用实际日期与地点身份。新写入矛盾日期被阻止并定位字段；旧记录保留原值、提示待核对并暂停回放，无关记录仍可保存。
- 上游非法时刻留空且不推进跨日游标，来源警告进入核对流程；完全空表返回结构化错误。RailGo 空结果、坏坐标和异常几何不进入成功缓存，可靠停站仍可参与明确标注的示意降级。
- 绘制与取景共享旧版 `legs` 几何。待补全记录的选择状态不再随地图移动丢失；关闭跟随后播放结束、暂停和尺寸变化保留自由视角。视频标签与取景共用标题、底栏遮挡范围。
- 草稿在恢复和继续前检查结构，兼容合法旧草稿及字段来源对象，拒绝坏行、停站、路段、候选和未知版本。坏草稿在预览中单独说明，原文可随恢复材料再次导出；无效正式记录也不会导致有效兄弟项的预览报错。
- 当时增加独立 Node 24 浏览器 CI 任务和失败报告保存，后按用户要求移除；可重复执行的合成性能基线继续保留。性能结果与边界见 [性能基线](PERFORMANCE.md)。

## 自动验证

测试以本地夹具与模拟上游为主，不依赖公开来源当天是否可用。Node 测试使用 `fake-indexeddb`；HTTP 测试使用真实临时回环端口；Chrome 测试使用独立 `127.0.0.1:43717` 和新浏览器上下文，双页面并发用同一上下文，确实共享数据库。

```sh
pnpm run test
pnpm run build
pnpm run check
pnpm run test:browser
```

接近时长上限的实录单独启用，避免常规回归每次都等待五分钟：

```sh
TRAVEL_VIDEO_LONG=1 pnpm exec playwright test tests/browser/video.spec.mjs --grep '@near-limit'
```

## 数据与发布边界

- 未启动或改写个人使用的 `127.0.0.1:4173` 数据来源；未清理或覆盖用户浏览器记录。本轮迁移、坏数据救援和备份恢复验收全部使用合成数据与隔离来源。
- 启用个人来源新版前，应先导出可恢复数据并关闭旧页面。v1 原文会保留，新版只写 IndexedDB；回退代码必须兼容新数据库。
- 本轮没有重新联网核实 12306、航旅纵横或 RailGo，外部来源核实日期保持 2026-09-21。离线模拟测试通过不能保证公开接口随时可用。
- `prepare-data.mjs` 流程已用合成输入验证，没有重新生成随包真实地点和线路数据。
- 视频体积按目标码率估算，实际编码可能不同。近上限测试验证真实长片，不代表把样本文件实际填充到 250 MB；容量与异常路径另由故障注入和预算测试覆盖。
- 手机目标为响应式布局；本轮使用 390×844 浏览器视口验证，没有宣称已在实体手机验收。
