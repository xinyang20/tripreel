# 途映 · TripReel

[在线使用](https://tripreel.xinyang20.cn) · [GitHub 仓库](https://github.com/xinyang20/tripreel) · [MIT 许可](LICENSE) · [数据来源](docs/SOURCES.md)

> 把走过的路，映成故事。

途映把火车和飞机行程串成可回放、可导出视频的旅行地图，支持本机使用，也可由维护者按受限公开模式部署。目前覆盖中国大陆火车和飞机行程，无需注册账号或配置 API Key。

记录、线路、草稿和旅程分组保存在当前浏览器的 IndexedDB 中。项目没有账号、云同步或服务端数据库；在线查询不可用时，仍可先保存待补全记录。

## 能做什么

| 功能           | 使用方式                                                           |
| -------------- | ------------------------------------------------------------------ |
| 单段与批量录入 | 手动填写，或每行粘贴一段行程，查询后核对保存；批量最多 20 段       |
| 草稿与补全     | 自动保存未完成输入；缺时刻、坐标或线路的记录可先保存，之后继续补齐 |
| 铁路来源       | 保存默认来源，或为单次／整批临时选择；新参考线路预览后明确接受     |
| 旅程与筛选     | 按旅程、年份、日期、交通方式和关键词筛选，列表、统计和地图同步     |
| 地图回放       | 连续铁路、飞行示意弧线、2D/3D 视角、全屏及 0.5×—32× 回放           |
| 视频导出       | 浏览器内生成 720p/1080p 视频，MP4 优先、WebM 回退，无需录屏权限    |
| 备份恢复       | 导出 JSON，在恢复预览中核对新增、重复、冲突及损坏内容              |

**最新线路、参考时刻和示意曲线都不等于出行当天的真实轨迹。** 项目保留来源及确认状态，不能用于证明实际停站、调度或飞行路径。

## 安装、启动与停止

需要 Node.js 22 或以上、pnpm 10.32.1。下载或克隆仓库后，在项目根目录执行：

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run start
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。已有依赖和运行库时，之后只需执行 `pnpm run start`；macOS 也可双击 [启动途映.command](启动途映.command)。不要直接打开 `dist/index.html`。

在启动终端按 `Ctrl+C` 停止服务。停止服务不会删除浏览器记录；本机启动没有自动启动或后台常驻配置。服务固定监听本机 `127.0.0.1:4173`，默认不提供局域网或公网访问。

请固定使用同一浏览器和地址。`localhost`、`127.0.0.1`、不同端口属于不同存储来源，记录不会自动互通；更换浏览器或地址前先导出 JSON 备份。

### 公开部署模式

公开站点使用 HTTPS 和反向代理，Node 服务仍只监听本机。维护者须显式配置公开来源并停用 RailGo 在线接口，配置步骤见 [部署说明](docs/DEPLOYMENT.md)，各次本地验证与上线检查按日期记录在 [验收记录](docs/VALIDATION.md)。

公开模式只允许 OSM 本地铁路来源，服务端强制阻止 RailGo 查询。已核验区间提供需确认的“OSM 线路参考”；未覆盖区间在有可靠停站时提供 12306 停站连线，也可手动补充途经点生成示意。航班、备份、回放和视频功能保留。参考及示意都不能当作实际乘车日的真实轨迹，查询不可用时可保存待补全记录。当前源码的 OSM 功能尚未发布到在线站点。

HTTPS 域名与本机地址是不同存储来源。首次迁移时，在原浏览器的本机页面导出 JSON 备份，再到 HTTPS 站点导入并核对。公开部署不新增账号或云同步；记录仍保存在访问站点的浏览器中，服务器不会替你保存备份。

## 选择铁路来源

OSM 是 OpenStreetMap（开放街图），由社区维护开放地图资料。这里使用其中的轨道几何建立有限的本地线路库；它不是实时车次或时刻查询服务，列车停站与时刻仍单独查询。

| 来源         | 本机模式                   | 公开模式               | 适用范围                                             |
| ------------ | -------------------------- | ---------------------- | ---------------------------------------------------- |
| RailGo       | 初始默认，可用性取决于上游 | 服务端禁止             | 查询并校验最新可用车次线路，具体限制见来源说明       |
| OSM 本地线路 | 可选                       | 默认且唯一可选铁路来源 | 仅已独立核实的车次与区间，返回需确认的“OSM 线路参考” |

在“数据与说明”的“新查询的默认来源”保存偏好；单段表单的“本次线路来源”和批量录入的“本批火车线路来源”只影响本次查询。切换来源会取消旧查询并撤销候选确认，保留手动填写的时间；已有记录不会随偏好批量改写。后台刷新沿用记录原来源，OSM 首版需要主动重新查询。恢复草稿时若原来源不可用或数据版本已变化，需要重新查询。

首版 OSM 覆盖 **G1 在沧州西、德州东、曲阜东、南京南之间的同向合法子区间**，例如沧州西至南京南；不提供反向区间。2026-10-02 核对的 G1 不停天津南，G813 尚未纳入。首批映射有效期为北京时间 2026-10-02 至 2026-11-01（含首尾）；过期或停站变化后不再提供该轨道候选，有可靠停站时降为需确认的示意，否则保留待补全状态。已有保存线路不会因到期被删除。

当前覆盖范围与失败原因以来源提示和查询结果为准。OSM 参考和示意候选均需预览并明确接受；主动更换来源也不会自动接受这些候选。覆盖依据、ODbL 归属和更新方法见 [数据来源](docs/SOURCES.md)。

## 录入第一段行程

1. 添加行程，填写交通方式、编号、实际出行日期和起止地点；时刻、坐标和线路可以暂缺。
2. 查询并核对地点、时刻、日期和来源。查询缺数据时，可以保留已有输入，保存为待补全记录。
3. 确认保存后，在列表继续编辑；时刻完整、路线可用且必要确认完成的记录，才能进入回放和视频。

批量录入每行一段。以下仅为格式示例，不代表真实班次或时刻：

```text
火车 G1 2027/1/8 北京南-上海虹桥
飞机 CA1001 2027/1/9 北京首都-厦门高崎
2027-01-10 G2 上海虹桥 北京南 06:30 11:24
2027-01-11 CA1002
```

点击“自动匹配并预览”，在列表核对结果。可筛选需核对、待补全和重复项，展开修改、选择候选、仅重试失败项，或批量确认选中的参考时刻。缺少起止地点的行仍需补齐最低保存字段；重复项默认不勾选。

匹配期间可停止匹配并核对已完成项，输入不会清空。只有确认保存才创建正式记录；选中项一起通过校验后提交，失败不会部分保存。单段和批量编辑会自动保存草稿，可在刷新后继续，恢复草稿本身不重新查询。

### 日期与参考结果

- 所有时间使用北京时间（UTC+8）。实际出行日期、列车始发查询日期和参考日期分别保存；中途上车和跨午夜行程会复核日期。
- 实际出行日期须与出发时刻日期一致，跨日到达不受影响。矛盾的旧记录保留原值并提示核对，修正前不回放，也不会阻止其他正常记录保存。
- 可只填一个时刻；已填时刻必须有效。两端时刻完整时，到达须晚于出发、单段不超过七天，并检查与其他行程是否重叠。
- 查询失败后可使用明确标注的今日参考候选；确认后仍保留参考属性，不能据此判断真实出行日的航班状态。异常时刻会留空并提示，不用于推算后续跨日日期。
- 重新匹配保留原文明确填写和手动修改的字段。机场支持中文名称、IATA 三字码和 ICAO 代码；高级设置可补充 WGS84 坐标及途经站。

### 线路与候选确认

| 线路类型       | 含义                                                                     |
| -------------- | ------------------------------------------------------------------------ |
| 最新车次线路   | 校验通过的连续轨道，只取实际乘坐区间；不等于乘车当天的真实轨迹           |
| 同线区间参考   | 仅用于已核对的共线区间，具体适用范围见 [数据来源](docs/SOURCES.md)       |
| OSM 线路参考   | 开放轨道资料与独立车次依据对应的有限区间；需预览确认，不代表当日实际径路 |
| 停站连线示意   | 根据可靠的有序停站数据生成，需明确确认，不是实际铁轨                     |
| 手动途经点示意 | 根据手动补充的点生成，保留手动来源，同样需要确认                         |
| 飞行示意弧线   | 机场之间的视觉弧线与高度，不代表真实飞行轨迹                             |

重复站名需要选择具体站次；信息不足时只显示已知起止点，不虚构连接。新的示意候选未经确认不会参与回放或视频；已有主线继续保留。直接保存或只改时刻不会接受候选，只有明确接受此候选后才替换并保留旧版本。修改编号、实际日期、区间、坐标或途经点后，需要重新匹配。

自动刷新只接受同等或更高质量的有效线路，失败保留旧线，不改票面时刻。详情可查看来源、参考日期、最近尝试及线路历史；保留当前和最近三个不同线路版本，可固定当前版本或恢复并固定旧版本。解除固定后，只有来源可用且支持自动刷新时才会后台更新；OSM 首版须主动重查。

## 旅程、地图与回放

可以创建、重命名旅程，勾选多条记录批量归组。解散分组只解除归属，不删除记录。各筛选条件按交集生效，列表、统计、地图和默认回放范围同步；未知里程不会计作零公里。

地图默认使用本地简约底图，也可主动切换在线精细底图。播放中显示当前段起止地点和移动列车的车次，总览显示全部起止地点；同城拥挤标签合并为城市，放大或播放时恢复具体地点。没有记录的两段行程之间不会生成连接路线。

地图工具使用文字按钮：“总览”查看当前范围的完整旅程，“全屏／退出”切换显示范围，“三维”切换 2D/3D 视角，“地图”切换底图，“导出视频”打开视频选项。窄屏通过“更多”展开“三维”和“地图”。关闭“跟随”后，暂停、播放结束和尺寸变化保留自由视角；主动总览、选择行程或重新开启跟随可重新取景。选择待补全记录后，仍可查看其有效起止地点。

大量行程的筛选、保存和回放已做增量更新与缓存。500 段／15 万主线路点和单条 15 万点的合成数据验证结果见 [性能记录](docs/PERFORMANCE.md)，结果取决于浏览器与图形后端。首次打开仍会读取完整线路和历史，软件渲染环境也可能较慢；这些限制不能由热态取景或单条保存的耗时代表。

下拉框、勾选标识、焦点和禁用状态使用统一样式。支持可定制下拉框的浏览器也会显示定制选项菜单，其他浏览器使用系统菜单；日期、时间和文件选择保留原生交互。控件可通过 Tab 移动焦点、方向键选择、空格切换勾选，不同浏览器的弹出界面可能不同。

## 数据保存与备份

记录只保存在当前浏览器；浏览器清理网站数据会影响记录。示例展示与个人保存状态分开。跨页面同时修改同一条记录时，会阻止旧版本覆盖，保留输入供核对。

在“数据与说明”中选择“导出完整备份”，保存 JSON 文件。备份包含记录、完整线路、字段来源、分组和线路历史，默认包含草稿，可取消。**视频不能替代 JSON 备份。**

恢复前会逐项预览新增、重复、冲突和无效条目。默认保留现有冲突项，选中内容一次提交，不会默认清空数据库。损坏草稿单独列出原因，原内容保留为可导出的恢复材料，不影响有效行程恢复；继续已有损坏草稿时也会保留内容并说明问题。

兼容旧版 `{ version: 1, trips: [...] }` 备份。首次打开新版会迁移旧 `travel-trace.v1` 数据，并保留原文；单条损坏内容被隔离，整份解析失败时显示恢复入口。升级前先导出备份、关闭旧页面；迁移后不要用只写旧版存储的程序继续编辑。

IndexedDB 不可用或容量不足时，请保留页面输入并导出可用恢复材料，不要通过清除网站数据处理。备份由你自行保管，项目没有云端副本。

## 视频导出

默认导出当前筛选范围；如果勾选了行程，则仅导出当前范围内的勾选项。待补全条目会被跳过并显示数量。可选择隐藏具体日期、隐藏编号、仅显示城市；这些选项不修改原始记录，数据归属及参考／示意说明仍保留。

支持 720p、1080p 和 1×—32×。面板推荐预计约两分钟以内的最低倍速，并显示预计时长和体积。预计超过五分钟或 250 MB 时，需要提高倍速或缩小范围；实际数据超过上限也会停止。

视频在浏览器内生成，不上传行程、不要求录屏权限，也没有服务器转码。优先尝试 MP4，不可用时回退 WebM；预览解码成功后提供下载，扩展名与实际格式一致。导出时请保持页面可见；取消、关闭或切到后台会结束本次生成，可再次导出。

浏览器、硬件和编码能力会影响导出。已执行的浏览器及 QuickTime 验收按日期记录在 [验收记录](docs/VALIDATION.md)，不代表每次更新都已重复全部验证。

## 常见问题

| 情况                       | 建议                                                                                                                 |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 页面打不开                 | 检查启动终端是否仍在运行，使用完整的 `http://127.0.0.1:4173`；首次启动前执行安装和构建                               |
| 提示 4173 端口被占用       | 先确认占用服务的归属；若为自己此前启动的途映，可返回原终端停止后重启，不要停止其他项目                               |
| 换地址或浏览器后记录不见了 | 返回原浏览器和原地址导出 JSON，再在新位置导入；不同来源的数据不自动共享                                              |
| 查询失败、只有参考结果     | 在“数据与说明”查看来源连接摘要，核对编号、日期和地点；保留输入，可先保存待补全记录                                   |
| OSM 提示未覆盖或已过期     | 核对车次、方向和覆盖提示；有可靠停站时可确认示意，或手动补充途经点，不会自动改用 RailGo                              |
| 更改默认来源后旧线路没变   | 偏好只影响新查询；编辑该记录并主动重查，预览和接受新候选后才替换旧线                                                 |
| 大行程首次打开较慢         | 首次仍读取完整线路与历史；等待加载后缩小筛选范围，性能测量与图形后端限制见性能记录                                   |
| 大行程地图或视频卡顿       | 检查浏览器硬件加速，先缩小筛选或导出范围；软件 WebGL 尚未达到本次 500 段交互目标，见 [性能记录](docs/PERFORMANCE.md) |
| 已保存但不能回放           | 查看是否缺时刻、坐标或有效线路，以及参考时刻、示意候选和日期矛盾是否已核对                                           |
| 视频生成失败               | 保持页面可见，先缩小行程范围、降低至 720p 或提高倍速；使用预览成功后提供的实际格式文件                               |
| 保存失败或内容损坏         | 保留输入和原有数据，导出可用恢复材料；不要先清空浏览器存储                                                           |

## 使用边界与许可

查询会向固定来源发送编号和查询日期，在线精细底图会请求地图服务。已有完整路线及本地底图可在本地服务运行时离线使用；公开查询来源的可用性没有保证。

项目自有代码采用 [MIT License](LICENSE)。第三方代码、数据和服务仍遵循各自许可与使用条件，MIT 不替代这些条款。数据归属、坐标约定及访问边界见 [数据来源](docs/SOURCES.md)，第三方许可保留在 [licenses/](licenses/)。

公开代码不代表取得第三方服务的转授权。受限公开模式禁用 RailGo 在线接口，并保留固定来源、Host/Origin 检查、请求体限制和请求预算；维护者还需配置反向代理、TLS 及 CDN 缓存边界。该模式没有账号系统或云端个人数据库，具体步骤和限制见 [部署说明](docs/DEPLOYMENT.md)。
