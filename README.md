# 途映 · TripReel

> 把走过的路，映成故事。

把火车和飞机行程串成可回放的旅行地图。面向个人在本机使用，记录、线路、草稿和旅程分组保存在当前浏览器的 IndexedDB 中。无需注册账号或配置 API Key；公开查询服务缺数据时，可以先保存待补全记录。

保持白色、浅蓝色界面，支持连续铁路、飞行示意弧线、三维取景、地图全屏、同城标签合并、0.5×—32× 回放，以及浏览器内视频导出。

## 启动与停止

需要 Node.js 22 或以上、pnpm 10.32.1。所有命令在本文件所在目录执行。

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run start
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。已有依赖和运行库时直接执行 `pnpm run start`，或双击 [启动途映.command](启动途映.command)。在启动终端按 `Ctrl+C` 停止；停止服务不会删除浏览器记录。项目没有自动启动或后台常驻配置。

固定使用同一浏览器和地址。`localhost`、`127.0.0.1`、不同端口属于不同存储来源，记录不会自动互通；更换浏览器请通过 JSON 备份恢复。不要直接打开 `dist/index.html`。

## 录入和继续补全

单段录入填写交通方式、编号、实际出行日期和起止地点，可查询补齐时刻，也可以直接确认保存待补全记录。时刻、坐标和线路不是保存的前提。只有时刻完整、地点有效、线路可用且确认完成的记录，才能进入回放和视频。

批量录入每行一段、最多 20 段，支持以下格式（均为格式示例，不代表真实时刻）：

```text
火车 G1 2027/1/8 北京南-上海虹桥
飞机 CA1001 2027/1/9 北京首都-厦门高崎
2027-01-10 G2 上海虹桥 北京南 06:30 11:24
2027-01-11 CA1002
```

点击“自动匹配并预览”后，在紧凑列表核对结果。可筛选需核对、待补全和重复项，展开修改、选择候选、仅重试失败项、批量确认选中的参考时刻。地点名称不全的记录仍需补齐最低保存字段；没有准确时刻或线路的记录可保存后再补。

匹配期间可“停止匹配并核对已完成项”，已识别内容与输入不会清空。只有点击确认保存才创建正式记录；选中项一起通过校验后事务提交，失败不部分保存。重复项默认不选中。

单段与批量编辑自动保存草稿，保留原文、修改、候选和勾选状态。刷新后通过“继续未完成草稿”恢复；恢复本身不重新查询。草稿不自动过期，可明确丢弃。正式保存成功时会同时删除对应草稿。

### 日期、来源和确认

- 所有时间使用北京时间（UTC+8）。实际出行日期、列车始发查询日期和参考日期分别记录。中途上车遇到跨日，会根据停站偏移复核一次始发日期，仍有差异则提示核对。
- 可只填一个时刻；已有时刻必须有效。时间完整时到达须晚于出发、单段不超过七天，并核对与其他行程是否重叠；时间不完整时提示冲突尚未核对。
- 重新匹配保留原文明确填写和手动修改的字段，允许更新自动填入的内容。旧时刻来源未知时保守保留，可手动采用查询时刻。
- 所选日期查询失败后，可继续使用明确标记的今日参考候选。参考数据确认后仍标注参考属性，不能用于判断真实出行日的航班状态。
- 机场支持中文名称、IATA 三字码和 ICAO 代码；名称纠错、多候选、区间不符需要核对。高级设置可填 WGS84 坐标及途经站。

## 线路及版本

| 线路类型       | 含义                                                                               |
| -------------- | ---------------------------------------------------------------------------------- |
| 最新车次线路   | 校验通过的本车次连续轨道，只取实际乘坐区间；最新线路不等于出行当天的真实轨迹       |
| 同线区间参考   | 仅用于已核对的共线区间；目前 G813 限天津南至南京南及其合法子区间                   |
| 停站连线示意   | 可靠的同一份有序停站数据生成的连续曲线，需点击“使用停站连线示意”确认；不是实际铁轨 |
| 手动途经点示意 | 根据手动补充的点生成，明确标明手动来源，同样需要确认                               |
| 飞行示意弧线   | 机场之间的视觉弧线与高度，不代表真实飞行轨迹                                       |

示意候选未经确认不会进入回放或视频，可以保留候选并先保存待补全记录。重复站名须选择具体站次，中间站缺坐标不能静默跳过。信息仍不足时仅展示已知起止点，不虚构连接。

自动刷新只接受同等或更高质量的有效线路，失败保留旧线，且不改票面时刻。详情可查看来源、参考日期、最近尝试及线路历史；保留当前和最近三个不同线路版本，可固定当前版本、恢复并固定旧版本，再按需重新启用自动更新。

已确认的旧示意记录保留；新的不同停站示意仍需核对。无需为了更新线路而删除重加。

## 旅程、筛选与地图

可以手动创建、重命名旅程，勾选多条记录批量归组或移至未分组。解散分组只解除归属，不删除记录。

旅程、年份、日期范围、交通方式和关键词按交集筛选。列表、统计、地图和默认回放范围同步；待补全记录始终可查找和编辑。距离分为铁路几何、停站示意和机场间距离，未知里程不当作零公里。

地图使用本地简约底图，也可切换在线精细底图。移动列车标签显示车次；播放中仅显示当前段起止地点，总览显示全部起止地点，同城拥挤标签合并为城市，放大或播放恢复具体地点。全屏隐藏顶栏和信息栏，容器、播放栏或视角变化后重新取景；关闭跟随后保留自由视角。

窄屏提供固定添加、粘贴入口，可收起播放栏和展开低频工具。对话框支持键盘操作；系统减少动画偏好会影响地图镜头过渡。

## 保存、迁移与备份

所有正式写入通过 IndexedDB 事务执行，成功后才显示已保存。不同页面新增不同记录可以合并；同一记录版本冲突会阻止旧内容覆盖，输入保留供核对。跨页面通知只传数据版本，不覆盖正在编辑的表单。

首次打开新版会从 `travel-trace.v1` 迁移，迁移本身不联网、不重算线路，原始 v1 内容保留。迁移后只写新数据库。单条损坏数据被隔离；仅线路坏的记录可转待补全；整份 JSON 解析失败会显示恢复入口，不伪装成空库。

“数据与说明”提供：

- 导出版本化 JSON：包含记录、完整线路、字段来源、分组、线路历史，默认包含草稿，可取消。
- 导入预览：兼容旧 `{version:1,trips}` 与新版备份，区分新增、重复、冲突和无效条目。冲突默认保留现有，选中内容一次提交；没有默认整库替换。
- 原始恢复材料下载：保留损坏内容，便于后续核对。
- 旧页面差异核对：迁移后若旧页面继续修改 v1，提示预览差异，不自动覆盖新版。
- 最近备份时间、来源连接与请求处理诊断摘要。

升级前先导出可恢复数据，关闭旧页面，再打开新版验收。迁移后不能回退到只写 v1 的旧程序继续编辑。IndexedDB 不可用或容量不足时保留输入和原始内容，导出可用恢复材料；不要通过清除网站数据“修复”。备份文件由你自行保管，视频不等于行程备份。

## 视频导出

默认导出当前筛选范围；如果勾选了行程，则只导出当前范围内的勾选项。待补全条目不会加入视频，面板说明跳过数量。可独立选择隐藏具体日期、隐藏编号、仅显示城市；选项作用于标题、标签、时间栏及文件名，不修改原始记录，数据归属和参考／示意说明仍保留。

支持 720p、1080p 和 1×—32×。首次推荐预计控制在约两分钟的最低倍速，仍可修改。显示预计时长及按目标码率估算的体积；预计超过五分钟或 250 MB 时须提高倍速或缩小范围，实际数据超过上限也会停止。请保持页面可见；取消、关闭、进入后台、编码或 WebGL 失败都会收尾，可再次导出。

优先尝试 H.264 MP4，再尝试其他 MP4 和 WebM。实际预览解码成功后提供下载，扩展名跟随实际编码；修改扩展名不是格式转换。视频在浏览器内生成，不需要录屏权限，不上传个人行程，也没有服务器转码。

本轮实际浏览器、QuickTime 验收与未覆盖边界见 [验收记录](docs/VALIDATION.md)。单个样本通过不保证任意机器、任意规模都能成功。

```text
tripreel/
├── README.md                 使用说明
├── AGENTS.md                 开发与代理协作规则
├── docs/                     数据来源、验收记录、GitHub 上传说明
├── licenses/                 第三方许可
├── dist/                     前端源码和公开运行数据
├── scripts/                  构建、数据整理及查询工具
├── tests/                    单元、服务与隔离浏览器回归
├── .github/workflows/ci.yml   自动检查，不部署网站
├── server.mjs                本机 HTTP 服务
├── package.json              命令与锁定的包管理器版本
├── pnpm-lock.yaml            依赖锁文件
└── 启动途映.command          macOS 启动入口
```

GitHub 仓库准备、迁移兼容性和许可状态见 [上传说明](docs/GITHUB.md)。本次改名保留数据库和备份中的 `travel-trace` 标识，确保既有记录可继续读取。

维护前阅读 [AGENTS.md](AGENTS.md)。保留原生 JavaScript ES modules、Node HTTP、MapLibre 和 Three.js 技术栈。

**`dist/` 是前端源码目录，不可整体删除。** `pnpm run build` 仅复制浏览器运行库并检查入口。修改浏览器源码后刷新即可；修改服务端或其导入模块后需重启。`dev` 与 `start` 相同，没有自动重启。

| 模块                                           | 职责                                       |
| ---------------------------------------------- | ------------------------------------------ |
| `domain.js` / `repository.js` / `store.js`     | 数据校验与可用性、事务存储与迁移、页面状态 |
| `editor*.js` / `batch-*.js`                    | 会话取消、草稿、匹配、字段来源及确认       |
| `selectors.js` / `library-ui.js`               | 统一范围、旅程、备份恢复与详情             |
| `routes.js`                                    | 后台线路刷新，不修改时刻                   |
| `map*.js` / `camera-fit.js` / `replay.js`      | 场景、地名、动态取景和回放                 |
| `video-options.js` / `video-export.js`         | 导出范围、预算、隐私呈现、编码与收尾       |
| `server.mjs` / `scripts/request-scheduler.mjs` | 固定来源代理、超时、去重、取消及队列       |
| `scripts/rail-*.mjs` / `train-reference.mjs`   | 铁路几何校验、停站降级及参考日期           |

API 保留 `/api/train`、`/api/flight`、`/api/route`，新增 `/api/diagnostics`。线路通过 `resolution.state` 区分 `ready`、`needs-confirmation`、`unavailable`；错误含 `error`、稳定 `code` 和 `retryable`。服务创建入口 `createTravelServer(...)` 可注入假上游并监听临时端口，正常启动仍固定 `127.0.0.1:4173`。

单次上游最长 18 秒，列车含回退与线路查询各 75 秒，单日期航班 20 秒。单行完整匹配 150 秒，一批最多等待五分钟。客户端留传输余量并受父级期限约束。RailGo 串行、约 1.2 秒间隔、最多 24 个等待项；相同请求共享，全部订阅取消才中止上游。主动取消和总期限到达不继续回退。诊断的来源成功时间表示连接与解析成功，不保证某条线路匹配成功。

数据生成使用显式输入参数，完整校验后发布，失败保留旧文件：

```sh
pnpm exec node scripts/prepare-data.mjs --stations /path/to/rail-stations.csv --station-names /path/to/station_name.js --airports /path/to/airport-codes.csv --source-date YYYY-MM-DD
```

普通安装不需要生成数据。来源、取得日期、许可和坐标系记录见 [数据来源](docs/SOURCES.md)。外部来源核实日期仍是 2026-09-21，本轮本地模拟测试不代表重新核实接口可用性。

## 测试

```sh
pnpm run test
pnpm run build
pnpm run check
pnpm run test:browser
```

Node 测试使用本地夹具、fake-indexeddb、假上游和临时端口；浏览器测试使用独立 `127.0.0.1:43717` 来源与隔离浏览器上下文，双页面并发测试共享同一上下文。默认使用本机 Chrome，测试服务结束自动关闭。格式化执行 `pnpm run format`；第三方运行库、大型数据文件、个人行程、截图和视频不纳入格式化或 Git。

Safari 和 QuickTime 验收必须使用真实应用，自动化 WebKit 不能替代。验证结果详见 [验收记录](docs/VALIDATION.md)。公开来源实时可用性需要另行核实，不是离线测试的保证。

## 使用边界

本项目没有账号、云同步、付费来源、公网部署或服务器视频转码。查询会向固定来源发送编号和查询日期；在线精细底图会请求地图服务。已有完整路线及本地底图可在本地服务运行时离线使用。

服务保留 Host/Origin 校验和请求体限制，不能改成任意 URL 代理。公开上线需单独确认授权、访问控制和运行维护方案；详见 [数据来源](docs/SOURCES.md) 与 [RailGo 许可](licenses/RAILGO-LICENSE.txt)。
